## 🎮 参加方法（初回のみ）

### 1. Forge 1.16.5 をインストール

1. [Forge ダウンロードページ](https://files.minecraftforge.net/net/minecraftforge/forge/index_1.16.5.html) にアクセス
2. **「Installer」** をダウンロード
3. ダブルクリックで実行 → **「Install client」** を選択してインストール

### 2. MODを導入

#### 方法A：zip一括導入（推奨・簡単）

1. 右の **「Releases」** タブをクリック
2. 最新のバージョン（例: `v1.0`）を開く
3. `mods.zip` をダウンロード
4. zipを展開して、中身を `.minecraft/mods/` フォルダに入れる
   - `mods` フォルダがない場合は自分で作成してください

#### 方法B：ServerSyncで自動同期

1. [ServerSync](https://www.curseforge.com/minecraft/mc-mods/serversync) をダウンロード
2. `serversync-client.jar` をダブルクリックで実行
3. サーバーIPを入力して同期
4. 完了したらMinecraftを起動

### 3. Minecraftを起動して接続

1. Minecraftランチャーを開く
2. プレイ → **「Forge 1.16.5」** を選択して起動
3. **マルチプレイ** → **サーバー追加**
4. アドレスに `xxx.playit.gg` を入力して保存
5. 接続！

## 🔄 MOD更新時

MOD構成を更新したときは、**Releasesページ**に新しい `mods.zip` をアップロードします。

更新があった場合：
1. このリポジトリの **Releases** を確認
2. 最新の `mods.zip` をダウンロード
3. `.minecraft/mods/` の中身を一度全部消去
4. 新しいzipの中身を入れる

## 🐛 トラブルシューティング

| 症状 | 解決方法 |
|------|---------|
| `Incomplete set of tags received` | MODが一致していません。最新の `mods.zip` を入れ直してください |
| `java.lang.OutOfMemoryError` | ランチャーの設定でメモリを4GB以上に増やしてください |
| サーバーに接続できない | サーバーが起動中か確認。掲示板とかで聞いて |
| 黄昏の森に入れない | ポータルの作り方を確認（2×2の水を花で囲んでダイヤモンドを投げ入れる） |

他わからない事があったら各自で調べて解決してください
